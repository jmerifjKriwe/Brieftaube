# ADR template

- Number: sequential (`NNNN`), directory `docs/adr/NNNN-short-name.md`
- Status: proposed | accepted | superseded by ADR-NNNN
- One decision per ADR. English. Written as part of the PR that implements
  the decision.

```markdown
# ADR-NNNN: <decision title>

Date: YYYY-MM-DD
Status: proposed | accepted | superseded by ADR-NNNN

## Context

The forces at play: requirements, constraints, options considered.
Keep it honest — include the options you rejected.

## Decision

What we will do, stated in present tense.

## Consequences

What becomes easier, what becomes harder, what we accept.
Include the trigger conditions for revisiting this decision.
```
